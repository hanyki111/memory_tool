# 판단 문서 가이드 (AI용)

답하는 질문: 왜 그렇게 보았거나 정했지?

판단 문서는 어느 시점의 결론과 근거를 남깁니다. 나중에 생각이 바뀌어도 고쳐 쓰지 않고, 새 판단 문서를 만들어 서로 링크합니다. 결정뿐 아니라 분석과 예측도 여기에 해당합니다.

## 질문

한 번에 하나씩 묻습니다.

- 결론을 한 문장으로 쓰면 무엇입니까?
- 언제 내린 판단입니까?
- 그렇게 본 근거는 무엇이고, 그중 직접 확인한 것은 무엇입니까?
- 검토했지만 택하지 않은 선택지는 무엇이고, 왜 택하지 않았습니까?
- 당시에 몰랐거나 가정한 것은 무엇입니까?
- 이 판단에 대한 가장 강한 반론은 무엇입니까?
- 무엇을 보면 이 판단을 바꾸겠습니까? 언제 다시 볼 예정입니까?

## 지적할 때

- 사실과 해석이 섞인 문장을 짚습니다.
- 결론을 먼저 정해 놓고 근거를 모은 것처럼 보이는 곳이 있으면 반론을 묻습니다.
- 나중에 안 사실을 예전 판단에 덧붙이려 하면, 새 판단 문서를 만들도록 권합니다.

## 점검

- 결론이 맨 앞에 있습니까?
- 날짜가 있습니까?
- 근거와 해석이 구분되어 있습니까?
- 기존 판단을 대체한다면 두 문서가 서로 링크되어 있습니까?
- 다시 볼 날짜가 있다면 `stale_after`에 적었습니까?
